# Changelog

## 0.1.0

- Initial NOVA reference implementation: lexer, parser, AST, static type checker, NOVA-IR compiler, bounded VM, CLI, examples, and tests.
- Added Windows launch/test scripts and GitHub Actions workflow.
- Confirmed Python 3.10+ as the active implementation runtime.

## Project decision update (2026-11-13)

- Reaffirmed Python as the active compiler/VM implementation language because the project owner already has Python installed.
- Superseded the experimental Rust Core direction; it is not part of the canonical repository.
- No NOVA language semantics or v0.1.0 features were changed by this decision.
