# RANCAGE 0.2 Stage 0 — M0.4 Virtual Machine Runtime Execution Architecture Specification

## 1. Architectural Overview

Milestone M0.4 implements reference execution semantics for RANCAGE-IR 0.2 bytecode. It extends [`VirtualMachine`](src/rancage/vm.py:11) in [`src/rancage/vm.py`](src/rancage/vm.py) from 23 legacy opcodes to 33 opcodes, adds intrinsic dispatch for 8 built-in operations plus `print`, enforces defensive validation on untrusted IR, and establishes bounded resource management.

Design adheres to three core tenets:
- **LIGHTWEIGHT**: Pure Python 3.10+ standard library implementation; zero third-party dependencies; minimal heap overhead.
- **SAFETY**: Strict sandbox boundary (no host OS, filesystem, socket, or process exposure); strict operand and boundary checks; hard caps on instruction budget, stack recursion, collection capacity, and string length.
- **STRONG**: Deterministic semantics; unambiguous distinction between missing map keys and null values; no silent host exceptions escaping [`RancageRuntimeError`](src/rancage/vm.py:7).

## 2. Runtime Object Model

Host Python primitives represent RANCAGE runtime values with explicit isolation:

| RANCAGE Type | Runtime Representation | Invariants & Boundaries |
|---|---|---|
| `int` | Python `int` | Arbitrary precision bounded by step/memory limits. Cannot be boolean (`type(v) is int`). |
| `float` | Python `float` | Finite IEEE 754 float. `math.isfinite(v)` enforced on literal loading and operations. |
| `bool` | Python `bool` | Strict boolean (`True` or `False`). |
| `string` | Python `str` | Immutable Unicode scalar sequence. Maximum length capped at `MAX_STRING_LENGTH`. |
| `null` | Python `None` | Null singleton reference. Dereference raises [`RancageRuntimeError`](src/rancage/vm.py:7). |
| `list[T]` | Python `list` | Ordered, homogeneous array. Mutated via index/push/pop. Capacity capped at `MAX_COLLECTION_SIZE`. |
| `map[string, V]` | Python `dict` | Hash table with string keys. Missing key lookup raises [`RancageRuntimeError`](src/rancage/vm.py:7). Capacity capped at `MAX_COLLECTION_SIZE`. |
| `record` | `RecordInstance` | Nominal product instance. Holds declared `name: str` and `fields: dict[str, Any]`. Field names validated against IR record metadata. |

### Record Class Definition:
```python
class RecordInstance:
    __slots__ = ("name", "fields")

    def __init__(self, name: str, fields: dict[str, Any]):
        self.name = name
        self.fields = fields

    def __repr__(self) -> str:
        return f"{self.name} {self.fields}"
```
`RecordInstance` isolates nominal user records from plain `dict` maps, eliminating accidental type confusion and preventing host object attribute injection.

## 3. Operand Stack and Call Stack

### Evaluation Stack
- Evaluated per activation frame (`stack: list[Any] = []`).
- Every expression evaluation leaves balanced stack entries.
- Operations popping from empty stack raise [`RancageRuntimeError("Stack underflow")`](src/rancage/vm.py:133).

### Call Stack & Activation Frames
- Managed via call recursion depth parameter in [`VirtualMachine._call()`](src/rancage/vm.py:77).
- Bounded by `max_depth = 128`. Exceeding limit raises [`RancageRuntimeError("Batas kedalaman pemanggilan fungsi terlampaui")`](src/rancage/vm.py:83).
- Locals stored in frame-isolated dictionary `locals_: dict[str, Any] = dict(zip(params, args))`.
- Instruction counter `self.steps` increments on each executed opcode; exceeding `max_steps = 1_000_000` raises [`RancageRuntimeError("Batas instruksi program terlampaui")`](src/rancage/vm.py:94).

### Function and Intrinsic Invocation Balance
1. Stack layout prior to call: `[..., arg0, arg1, ..., argN-1]`.
2. Caller pops `N` operands from stack and passes them to callee.
3. Every callee (user function or intrinsic) returns exactly **one** value:
   - Value-returning functions/intrinsics push returned object.
   - Void functions and void intrinsics (`push`, `print`) push `None` sentinel.
4. Expression statements compile to `[... expr ..., ["POP"]]`, discarding the returned value or `None` sentinel, guaranteeing net zero stack delta per statement.

## 4. Opcode Execution Semantics (10 Stage 0 Opcodes)

### 1. `MAKE_LIST`
- **Operands**: `[count: int]`
- **Stack Input**: `[e0, e1, ..., en-1]` (where `n = count`)
- **Stack Output**: `[list]`
- **Evaluation Order**: Operands pushed left-to-right; `en-1` is at stack top.
- **Validation**:
  - `count >= 0`.
  - `len(stack) >= count`.
  - `count <= MAX_COLLECTION_SIZE`.
- **Execution**:
  ```python
  elements = stack[-count:] if count else []
  if count: del stack[-count:]
  stack.append(elements)
  ```
- **Complexity**: O(N) time and space.

### 2. `LIST_GET`
- **Operands**: none
- **Stack Input**: `[list, index]` (top of stack is `index`)
- **Stack Output**: `[element]`
- **Validation**:
  - `index = self._pop(stack)`
  - `target = self._pop(stack)`
  - If `target is None`: raise [`RancageRuntimeError("Null reference dereference")`](src/rancage/vm.py:7).
  - If `type(target) is not list`: raise [`RancageRuntimeError("Operasi membutuhkan list")`](src/rancage/vm.py:7).
  - If `type(index) is not int` or `isinstance(index, bool)`: raise [`RancageRuntimeError("Indeks list harus integer")`](src/rancage/vm.py:7).
  - If `index < 0` or `index >= len(target)`: raise [`RancageRuntimeError(f"Indeks list di luar batas: {index} (panjang {len(target)})")`](src/rancage/vm.py:7).
- **Execution**: `stack.append(target[index])`.
- **Complexity**: O(1).

### 3. `LIST_SET`
- **Operands**: none
- **Stack Input**: `[list, index, value]` (top of stack is `value`, then `index`, then `list`)
- **Stack Output**: none
- **Validation**:
  - `value = self._pop(stack)`
  - `index = self._pop(stack)`
  - `target = self._pop(stack)`
  - If `target is None`: raise [`RancageRuntimeError("Null reference dereference")`](src/rancage/vm.py:7).
  - If `type(target) is not list`: raise [`RancageRuntimeError("Operasi membutuhkan list")`](src/rancage/vm.py:7).
  - If `type(index) is not int` or `isinstance(index, bool)`: raise [`RancageRuntimeError("Indeks list harus integer")`](src/rancage/vm.py:7).
  - If `index < 0` or `index >= len(target)`: raise [`RancageRuntimeError(f"Indeks list di luar batas: {index} (panjang {len(target)})")`](src/rancage/vm.py:7).
- **Execution**: `target[index] = value`.
- **Complexity**: O(1).

### 4. `MAKE_MAP`
- **Operands**: `[count: int]` (number of key-value pairs)
- **Stack Input**: `[k0, v0, k1, v1, ..., kn-1, vn-1]` (total `2 * count` stack elements)
- **Stack Output**: `[map]`
- **Validation**:
  - `count >= 0`.
  - `len(stack) >= 2 * count`.
  - `count <= MAX_COLLECTION_SIZE`.
  - Each key must be `str`.
- **Execution**:
  ```python
  total = 2 * count
  raw = stack[-total:] if total else []
  if total: del stack[-total:]
  m = {}
  for i in range(0, total, 2):
      k, v = raw[i], raw[i + 1]
      if not isinstance(k, str):
          raise RancageRuntimeError("Key map harus string")
      m[k] = v
  stack.append(m)
  ```
- **Complexity**: O(N) average time.

### 5. `MAP_GET`
- **Operands**: none
- **Stack Input**: `[map, key]` (top of stack is `key`)
- **Stack Output**: `[value]`
- **Validation**:
  - `key = self._pop(stack)`
  - `target = self._pop(stack)`
  - If `target is None`: raise [`RancageRuntimeError("Null reference dereference")`](src/rancage/vm.py:7).
  - If `type(target) is not dict` or `isinstance(target, RecordInstance)`: raise [`RancageRuntimeError("Operasi membutuhkan map")`](src/rancage/vm.py:7).
  - If not isinstance(key, str): raise [`RancageRuntimeError("Key map harus string")`](src/rancage/vm.py:7).
  - If `key not in target`: raise [`RancageRuntimeError(f"Key map tidak ditemukan: '{key}'")`](src/rancage/vm.py:7).
- **Execution**: `stack.append(target[key])`.
- **Complexity**: O(1) average time.

### 6. `MAP_SET`
- **Operands**: none
- **Stack Input**: `[map, key, value]` (top of stack is `value`, then `key`, then `map`)
- **Stack Output**: none
- **Validation**:
  - `value = self._pop(stack)`
  - `key = self._pop(stack)`
  - `target = self._pop(stack)`
  - If `target is None`: raise [`RancageRuntimeError("Null reference dereference")`](src/rancage/vm.py:7).
  - If `type(target) is not dict` or `isinstance(target, RecordInstance)`: raise [`RancageRuntimeError("Operasi membutuhkan map")`](src/rancage/vm.py:7).
  - If not isinstance(key, str): raise [`RancageRuntimeError("Key map harus string")`](src/rancage/vm.py:7).
  - If `key not in target` and `len(target) >= MAX_COLLECTION_SIZE`: raise [`RancageRuntimeError("Batas kapasitas koleksi terlampaui")`](src/rancage/vm.py:7).
- **Execution**: `target[key] = value`.
- **Complexity**: O(1) average time.

### 7. `MAKE_RECORD`
- **Operands**: `[name: str, fields: list[str]]`
- **Stack Input**: `[v0, v1, ..., vn-1]` (where `n = len(fields)`)
- **Stack Output**: `[record]`
- **Validation**:
  - `records_meta = self.program.get("records", {})`
  - If `name not in records_meta`: raise [`RancageRuntimeError(f"Tipe record tidak terdefinisi: '{name}'")`](src/rancage/vm.py:7).
  - Declared field names must match `fields`.
  - `len(stack) >= len(fields)`.
- **Execution**:
  ```python
  n = len(fields)
  vals = stack[-n:] if n else []
  if n: del stack[-n:]
  field_dict = dict(zip(fields, vals))
  stack.append(RecordInstance(name, field_dict))
  ```
- **Complexity**: O(F) where F is field count.

### 8. `GET_FIELD`
- **Operands**: `[field: str]`
- **Stack Input**: `[record]`
- **Stack Output**: `[value]`
- **Validation**:
  - `target = self._pop(stack)`
  - If `target is None`: raise [`RancageRuntimeError("Null reference dereference")`](src/rancage/vm.py:7).
  - If not isinstance(target, RecordInstance): raise [`RancageRuntimeError(f"Akses field '{field}' pada tipe non-record")`](src/rancage/vm.py:7).
  - If `field not in target.fields`: raise [`RancageRuntimeError(f"Field '{field}' tidak ditemukan pada record '{target.name}'")`](src/rancage/vm.py:7).
- **Execution**: `stack.append(target.fields[field])`.
- **Complexity**: O(1).

### 9. `SET_FIELD`
- **Operands**: `[field: str]`
- **Stack Input**: `[record, value]` (top of stack is `value`, then `record`)
- **Stack Output**: none
- **Validation**:
  - `value = self._pop(stack)`
  - `target = self._pop(stack)`
  - If `target is None`: raise [`RancageRuntimeError("Null reference dereference")`](src/rancage/vm.py:7).
  - If not isinstance(target, RecordInstance): raise [`RancageRuntimeError(f"Mutasi field '{field}' pada tipe non-record")`](src/rancage/vm.py:7).
  - If `field not in target.fields`: raise [`RancageRuntimeError(f"Field '{field}' tidak ditemukan pada record '{target.name}'")`](src/rancage/vm.py:7).
- **Execution**: `target.fields[field] = value`.
- **Complexity**: O(1).

### 10. `STRING_GET`
- **Operands**: none
- **Stack Input**: `[string, index]` (top of stack is `index`)
- **Stack Output**: `[char]` (1-character string)
- **Validation**:
  - `index = self._pop(stack)`
  - `target = self._pop(stack)`
  - If `target is None`: raise [`RancageRuntimeError("Null reference dereference")`](src/rancage/vm.py:7).
  - If not isinstance(target, str): raise [`RancageRuntimeError("Operasi membutuhkan string")`](src/rancage/vm.py:7).
  - If `type(index) is not int` or `isinstance(index, bool)`: raise [`RancageRuntimeError("Indeks string harus integer")`](src/rancage/vm.py:7).
  - If `index < 0` or `index >= len(target)`: raise [`RancageRuntimeError(f"Indeks string di luar batas: {index} (panjang {len(target)})")`](src/rancage/vm.py:7).
- **Execution**: `stack.append(target[index])`.
- **Complexity**: O(1).

## 5. Intrinsic Runtime Dispatcher

The dispatcher intercepts [`CALL`](src/rancage/vm.py:112) targets matching intrinsic names:

| Intrinsic | Arity | Argument Types | Return Type | Semantics & Edge Cases |
|---|---|---|---|---|
| `print` | 1 | `Any` | `void` (null) | Formats and outputs value via `self.output()`. Pushes `None`. |
| `len` | 1 | `list`, `map`, `string` | `int` | Returns element count, key count, or Unicode scalar length. Non-collection/null raises [`RancageRuntimeError`](src/rancage/vm.py:7). |
| `push` | 2 | `list`, `item` | `void` (null) | Appends `item` to list. If `len(lst) >= MAX_COLLECTION_SIZE`, raises [`RancageRuntimeError`](src/rancage/vm.py:7). Pushes `None`. |
| `pop` | 1 | `list` | element | Pops and returns last element. If `len(lst) == 0`, raises [`RancageRuntimeError("Operasi pop pada list kosong")`](src/rancage/vm.py:7). |
| `ord` | 1 | `string` | `int` | Returns Unicode scalar code point. If `len(s) != 1`, raises [`RancageRuntimeError("Fungsi ord membutuhkan string tepat 1 karakter")`](src/rancage/vm.py:7). |
| `chr` | 1 | `int` | `string` | Returns 1-char string for code point `cp`. If `cp < 0 or (0xD800 <= cp <= 0xDFFF) or cp > 0x10FFFF`, raises [`RancageRuntimeError(f"Code point Unicode tidak valid: {cp}")`](src/rancage/vm.py:7). |
| `slice` | 3 | `string, start, length` | `string` | Slices code points. If `start < 0 or length < 0 or start > len(s)`, raises [`RancageRuntimeError`](src/rancage/vm.py:7). Clamps `start + length > len(s)` to `len(s)`. If result > `MAX_STRING_LENGTH`, raises [`RancageRuntimeError`](src/rancage/vm.py:7). |
| `map_has` | 2 | `map, key` | `bool` | Checks `isinstance(key, str)` and returns `key in m`. Non-map/non-string raises [`RancageRuntimeError`](src/rancage/vm.py:7). |
| `map_remove`| 2 | `map, key` | `bool` | If `key in m`, deletes key and returns `True`. If `key not in m`, returns `False` without error. Non-map/non-string raises [`RancageRuntimeError`](src/rancage/vm.py:7). |

## 6. String and Unicode Semantics

1. **Scalar Value Indexing**: All indexing and slicing operations operate on Python `str`, which indexes Unicode code points directly in Python 3.
2. **Negative Indexing Rejection**: Negative indices are rejected dynamically with descriptive [`RancageRuntimeError`](src/rancage/vm.py:7).
3. **Surrogate Pair Safety**: `chr()` explicitly forbids surrogate code points (`0xD800` through `0xDFFF`) to prevent emitting malformed UTF-16 surrogates into UTF-8 runtime strings.
4. **Immutability Guarantee**: String values are immutable Python strings; indexing assignment is rejected at compile-time and has no corresponding bytecode opcode.

---

## 7. Null and Error Semantics

1. **Null Sentinel**: Represented as Python `None`.
2. **Null Equality**: `EQ` and `NE` handle `None` comparisons (`null == null` is `True`, `val == null` evaluates safely).
3. **Null Dereference Prevention**: Any access via `GET_FIELD`, `SET_FIELD`, `LIST_GET`, `LIST_SET`, `MAP_GET`, `MAP_SET`, `STRING_GET`, `len`, `push`, `pop`, `slice` on `None` raises [`RancageRuntimeError("Null reference dereference")`](src/rancage/vm.py:7).
4. **Missing Key vs Null**:
   - `MAP_GET` on non-existent key raises [`RancageRuntimeError`](src/rancage/vm.py:7).
   - `MAP_GET` on existing key whose value is `null` returns `None` without error.
   - Code must use `map_has(m, k)` to test existence before accessing nullable values.

## 8. Bytecode Validation and Defensive Execution

[`VirtualMachine._validate()`](src/rancage/vm.py:28) runs prior to execution on untrusted IR:

1. **Container Check**: `format in {"RANCAGE-IR", "NOVA-IR"}` and `version in {"0.1", "0.2"}`.
2. **Records Table Check**: If present, `records` must be `dict` mapping non-empty strings to `{"fields": [{"name": str, "type": str}, ...]}` with unique field names.
3. **Functions Table Check**: `functions` must be `dict` with `<= 10_000` entries; `entry` must exist in `functions`.
4. **Instruction Audit**:
   - Opcode must be one of 33 recognized instructions.
   - Arity and operand formats validated per instruction.
   - `CALL`: name must be in `functions` OR in `INTRINSICS`. If intrinsic, instruction arity must match intrinsic signature exactly.
   - `MAKE_RECORD`: record name must exist in `records` table, and operand fields list must match declared fields.
   - Jumps: target instruction index must be within `0 <= target <= len(code)`.

## 9. Memory and Resource Management

Defensive runtime limits:
- `MAX_STEPS = 1_000_000`: Program instruction step budget.
- `MAX_DEPTH = 128`: Call recursion depth limit.
- `MAX_COLLECTION_SIZE = 100_000`: Maximum elements in any single `list` or `map`.
- `MAX_STRING_LENGTH = 1_000_000`: Maximum length of any string instance (from `ADD` or `slice`).
- `MAX_FUNCTIONS = 10_000`: Maximum functions in bytecode payload.
- `MAX_INSTRUCTIONS_PER_FN = 1_000_000`: Maximum instruction array length in single function.

## 10. Security and Sandboxing

Strict reference sandbox preserved:
1. No OS imports (`os`, `sys`, `subprocess`, `socket`).
2. No dynamic code evaluation (`eval`, `exec`, `__import__`).
3. No host object reflection on user values (`getattr`, `setattr` on arbitrary host structures).
4. Sandboxed I/O: Only host interaction is formatted string output passed to injected `output` callable (defaults to `print`).
5. Memory containment: All collections and strings bound to runtime caps; cannot trigger host memory starvation.

## 16. Known Risks and Open Decisions

1. **Missing Map Key Semantics**:
   - Decision: `MAP_GET` on missing key unconditionally raises [`RancageRuntimeError`](src/rancage/vm.py:7).
   - Rationale: Preserves distinction between missing key and key holding value `null`.
2. **Map Remove Non-Existent Key**:
   - Decision: `map_remove` returns `False` when key is absent, without raising error.
   - Rationale: Consistent with standard boolean removal idioms in systems languages.
3. **Slice Length Clamping**:
   - Decision: If `start + length > len(s)`, slices up to `len(s)` without raising error. If `start < 0` or `start > len(s)`, raises [`RancageRuntimeError`](src/rancage/vm.py:7).
   - Rationale: Strictly complies with [`STAGE-0-PROPOSAL.md §3.2`](STAGE-0-PROPOSAL.md:52).

## 9. Post-Audit Remediations & Runtime Hardening

Following the independent security and runtime audit of M0.4, five critical defense-in-depth remediations were specified and implemented:

### 9.1 Finding 1: Record Field Ordering Permutations
- **Issue**: Bytecode validator strictly required field list equality, rejecting valid field permutations emitted by the compiler.
- **Remediation**: `VirtualMachine._validate()` validates that `MAKE_RECORD` fields match the declared fields by permutation (`len(field_list) == len(expected_fields)`, `sorted(field_list) == sorted(expected_fields)`, and uniqueness), supporting any initialization order safely.

### 9.2 Finding 2: Cycle-Safe Record and Collection Formatting
- **Issue**: Unbounded recursion (`RecursionError`) during `RecordInstance.__repr__()` or `print()` on self-referential or cyclic structures.
- **Remediation**: Replaced plain `__repr__` with `format_value(value, seen=set(), depth=0)`. Uses `id(value)` object identity tracking, emits `<cycle>` upon cycle detection, and bounds nesting depth to `MAX_FORMAT_DEPTH = 32` (emitting `{...}`, `[...]`, or `...`).

### 9.3 Finding 3: Signed 64-bit Integer Boundaries & Overflow Checking
- **Issue**: Unbounded integer bit growth in host Python integers during arithmetic operations.
- **Remediation**: Bound integers to signed 64-bit limits (`MIN_INT64 = -(1 << 63)`, `MAX_INT64 = (1 << 63) - 1`). Static rejection of out-of-range integer constants on `PUSH`, and runtime overflow detection raising `RancageRuntimeError` on `ADD`, `SUB`, `MUL`, `MOD`, and `NEG`.

### 9.4 Finding 4: Pre-Execution User Function CALL Arity Verification
- **Issue**: Arity for user-defined function `CALL` instructions was postponed until runtime execution.
- **Remediation**: Static bytecode validator `_validate()` now validates `argc == len(fn_params)` for all user function calls ahead of execution, rejecting arity mismatches at load time.

### 9.5 Finding 5: Cumulative Allocation Accounting
- **Issue**: Individual collection sizes were capped, but cumulative heap memory allocations in loops were unbounded.
- **Remediation**: Introduced deterministic unit accounting (`MAX_ALLOCATED_UNITS = 2_000_000`). Pre-allocation charges are enforced across `MAKE_LIST`, `MAKE_MAP`, `MAKE_RECORD`, `MAP_SET` (new key insertions), `push`, string `ADD`, `slice`, `chr`, and `STRING_GET`. Exceeding the cumulative budget raises `RancageRuntimeError("Batas alokasi memori program terlampaui")`.

Allocation units represent deterministic abstract semantic cost counters, not physical host RAM bytes or live operating system heap measurements.

#### Allocation Accounting Rates:

| Operation | Charged Units | Condition / Calculation |
|---|---|---|
| `MAKE_LIST` | `count + 1` | Bounded by `MAX_COLLECTION_SIZE` |
| `MAKE_MAP` | `count + 1` | Bounded by `MAX_COLLECTION_SIZE` |
| `MAKE_RECORD` | `n + 1` | `n = len(fields)` |
| `MAP_SET` | `1` or `0` | `1` on new key insertion, `0` on overwrite |
